# Manuals

Prose for the people who use the product: guidance, help text, explanations of product behavior and
troubleshooting. Engineering documentation lives in `docs/`.

A file being present here does not mean it is published. Material that matures here may later be
moved into the product's own help, docs, info or news content.

Record draft/reviewed status and applicable product behavior when a manual is added. Review affected
guidance when that behavior changes; publishing requires a separate product action.

Each manual is one Markdown file in this directory, linked from the list below.
