# MFA Passkey validity and admission regression

Verified against HEAD `f313b126931cfe3c9ecf64bbb72fb1cd3a0aada5`, with uncommitted authentication changes affecting the results.

APP/COM MFA previously accepted an expired or revoked Passkey after challenge issuance. The new real HTTP Email-primary/MFA test reproduced advancement to `/sign/in/check` at expiry instead of returning to the MFA chooser (seed 49841: one test, thirteen assertions, one failure). It starts with public Base admission, redeems it on Auth, performs Email primary verification and signs a real WebAuthn assertion. No ordinary Auth login is injected.

MFA now selects the owner-scoped credential under writer actor/credential locks and checks account availability, ACTIVE state and discard time before signature/counter verification and proof recording. The UI excludes expired credentials on the writer as well. Two new UI cases failed before this filter (seed 35277: two tests, ten assertions, two failures). Successful verification records the verifier's actual timestamp for last use and UV evidence, with no step-up freshness issuance.

Additional JSON partition tests reproduced errors for `null` (seed 24269: two tests, fifty-six assertions, two errors). Both endpoints now reject missing, empty, malformed, null, array, zero, boolean, missing/null/numeric/empty identifier and NUL identifier payloads through the existing refusal contract, preserving pending MFA and absent authentication evidence/root cookies.

The two old MFA controller files initially failed all sixteen cases because they bypassed admission (seed 46877). Their setup now redeems real Base admission; successes assert Auth records evidence and emits no root cookies. Their existing assertion stubs are transport/branch tests rather than signature evidence. Obsolete copied JWT/login/verification helper blocks were removed without changing shared test support. Test actors use owned deterministic IDs. The new integration covers real signatures and writer expiry immediately before/at/after the deadline on both surfaces, plus revocation after issuance.

Regression exposed PostgreSQL unlimited discard time as Ruby `Float::INFINITY`, which cannot be compared directly with `Time`. Primary and MFA expiry now use SQL predicates on the writer after locks. Primary HTTP coverage includes the unbounded sentinel as well as the three finite boundary points. This corrects the finite-only implementation recorded in `evidence/2026-10-04-primary-passkey-writer-expiry-3W9C.md`.
