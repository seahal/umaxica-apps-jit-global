# Current state-axis classification

Classification describes the transition authority; Confidence describes the strength of existing implementation evidence. Neither implies production reachability. `STATE_MACHINE` and `WORKFLOW_STATE` are the primary workflow investigation scope. `DERIVED_STATE` takes precedence when the visible state is a computed condition even if some inputs are persisted. A computed status cache such as MFA readiness therefore remains derived. `STATUS_AXIS` does not imply a machine integration target. `CANDIDATE` is reserved for unresolved classification.
