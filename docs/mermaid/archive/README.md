# Archived Mermaid diagrams

The `sign-*` Mermaid files in the parent directory are retained historical diagrams from the
pre-Base authority naming and are not current state-machine sources. The canonical diagrams for
the implementation cycle are the `idp-*` files listed in `docs/mermaid/README.md` and the current
section of `idp-state-machine-transition-inventory.md`.

They remain physically present only to preserve links from older ADRs and evidence. Do not update
their edges for new runtime behavior; amend the canonical `idp-*` diagram and inventory instead.
