# Search Engine Webmaster Tools

The public content surfaces use the following registered search-engine management services:

| Service               | Registration status |
| --------------------- | ------------------- |
| Google Search Console | Registered          |
| Bing Webmaster Tools  | Registered          |

This inventory records service-level registration only. Property scope, ownership verification, and
sitemap submission status must be confirmed in each provider's console because that external state
can change independently of this repository.

Do not store ownership-verification tokens or other provider credentials in this document.
